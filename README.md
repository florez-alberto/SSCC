# Sequence Space Coverage Calculator

A lightweight, self-contained web tool to compute expected probabilities and capacity limits for directed evolution experiments. 

## Features

*   **Compute Required S**: Calculate the required library size ($S$) to achieve a target probability of observing all variants.
*   **Compute Coverage $T_k$**: Calculate the probability ($T_k$) of observing your target variants given a specific library size.
*   **Compute Max L**: Calculate the maximum number of randomized codon positions that can be explored.
*   **Custom Sequence Design**: Define libraries with multiple groups of randomized positions and codon schemes (NNN, NNS/NNK, DKS, MAX).

## Usage

This tool is designed to be easily opened in a browser by double-clicking the `index.html` file.
