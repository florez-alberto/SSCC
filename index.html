Instructions & Definitions

This tool calculates the required parameters for saturation mutagenesis libraries based on Poisson statistics.

  • S (Library Size): The experimental library size. For instance, the total number of transformants or generated sequences.
  • Tk (Target Probability): The required probability (or confidence level) of sampling at least k variants. Typically 0.95 or 0.99.
  • k (Target Variants): The number of times you want to observe each variant in the theoretical sequence space. Setting this to 'Full' requires observing all theoretical variants.
  • L (Max Sequence Length): The maximum number of randomized codon positions that can be explored under the given parameters.
  • Codon Scheme: The randomization strategy used at each position (e.g., NNN, NNS/NNK, DKS, MAX).
  • Sequence Design (Blocks): Allows you to define a library with multiple groups of randomized positions.
